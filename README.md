# Markdown Dokumentation

### Liste over fordele

* Hurtigere at skrive end formateret tekst.
* Perfekt til noter og dokmentation.
* Gør det nemt at organiserer indhold. 

### Kode eksempel:

```
const fruits = 
["apple", "pineapple", "orange", "pear", "apricot"];

fruits.forEach(fruits) => {
    console.log(fruits);
}

```
